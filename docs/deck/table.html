What we do not claim.

  • We did not build the TEE. 0G did. We bind it to the client's intent.
  • Match runs in unattested code. No TDX host was available, so the client can check it and a stranger cannot. Closing that is next.
  • Reputation is not Sybil-proof. Faking it costs real inference and gas, and every client sits in the public index. Paid and visible, not impossible.
  • The 0G signature covers a fingerprint, not the answer's text. Same guarantee against tampering, accurate wording.
